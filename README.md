# PULSE LAB


음원을 브라우저에서 해독하고 타격음을 분석해 4키 리듬게임으로 만드는 정적 웹 앱입니다.


## 실행


Node.js가 설치된 환경에서 이 폴더를 열고 `npm start`를 실행한 뒤 http://127.0.0.1:4173 에 접속합니다. 외부 패키지 설치는 필요 없습니다. Worker를 사용하므로 index.html을 직접 더블클릭하지 말고 HTTP 서버로 여세요.


## 사용


1. MP3, WAV, M4A, OGG 등 브라우저에서 해독할 수 있는 파일을 선택합니다. 최대 50MB, 2초~10분입니다.
2. EASY / NORMAL / HARD로 노트 밀도를 선택합니다.
3. 플레이 시작 후 D F J K를 누르거나 화면 아래 4개 버튼을 터치합니다.
4. SPACE / ESC로 일시정지합니다. 노트가 음악보다 일찍 느껴지면 타이밍 보정을 + 방향으로 조절합니다.
5. 32초짜리 합성 데모 Midnight Circuit으로 파일 없이 체험할 수 있습니다.


음원은 서버에 업로드하지 않으며 메모리에서만 처리합니다. 새로고침하면 다시 선택해야 합니다. Google Fonts를 불러올 수 없으면 시스템 글꼴을 사용합니다.


## 구현 범위


- Web Audio API로 해독·재생, AudioContext 시각을 기준으로 노트 동기화
- Web Worker에서 10ms 프레임의 RMS 및 고주파 변화로 onset 감지
- 자기상관으로 고정 템포의 참고 BPM 추정. 실제 노트는 감지한 onset 위치에 배치
- 결정적인 레인 배치, 난이도별 최소 간격과 약한 타격음 제거
- PERFECT ±55ms / GREAT ±110ms / GOOD ±160ms, 이후 MISS
- 정확도, 점수, 최대 콤보, 결과 등급, 재시작, 창 전환 시 자동 일시정지
- 오디오 원본·사용자 파일·성적을 서버나 로컬 저장소에 보관하지 않음


자동 채보는 수작업 채보 수준의 음악적 패턴을 보장하지 않습니다. 보컬·지속음 위주 곡이나 가변 템포에서는 정확도가 낮을 수 있습니다. 현재는 단타 전용이며 롱노트, 편집기, 계정, 랭킹, 멀티플레이는 없습니다. BPM은 반박/배박으로 추정될 수 있습니다.


## 검증


`npm test`: 무음 처리, 합성 90/120/150 BPM onset 정확도, 난이도 간격, 판정 경계 테스트.


## 발전 방향


1. [osu!mania](https://osu.ppy.sh/wiki/en/Game_mode/osu!mania): 키 기반 세로 노트 플레이, 롱노트와 채보 편집기 참고.
2. [Audiosurf 2](https://store.steampowered.com/app/235800/Audiosurf_2/): 사용자의 음악으로 게임 경험을 만드는 방향 참고.
3. [DJMAX RESPECT V](https://store.steampowered.com/app/960170/DJMAX_RESPECT_V/): 타격 연출, 곡 선택, 결과 경험 참고.


우선순위: 드럼/비트 추적 정교화 → 채보 수동 보정 → 롱노트 → 구간별 시각 연출. 기존 게임의 자산을 포함하지 않습니다.
